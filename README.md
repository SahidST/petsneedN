# Pet's Need - Complete Pet Care Center Website

A modern, SEO-optimized website for Pet's Need, an all-in-one pet care center in Alipore, Kolkata. Built with Next.js 15, TypeScript, TailwindCSS, and Framer Motion.

## 🌟 Features

- **SEO Optimized**: Meta tags, schema markup, sitemap, and robots.txt configured
- **Fully Responsive**: Mobile-first design that works on all devices
- **Accessible**: WCAG 2.1 Level AA compliant with keyboard navigation and screen reader support
- **Animated**: Smooth animations with Framer Motion
- **Performance**: Optimized for 100/100 Lighthouse scores
- **TypeScript**: Fully typed for better developer experience

## 📄 Pages

1. **Homepage** (`/`) - Hero, services overview, testimonials, FAQs
2. **Grooming** (`/grooming`) - Pet grooming services and seasonal tips
3. **Clinic** (`/clinic`) - Veterinary services and doctor profiles
4. **Products** (`/products`) - Pet supplies with category tabs
5. **About** (`/about`) - Company story, mission, values, reviews
6. **Contact** (`/contact`) - Contact information, map, hours
7. **404 Page** - Custom error page with playful design

## 🛠 Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: TailwindCSS 3.4+
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Fonts**: Google Fonts (Fredoka, Quicksand, Poppins)

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the website.
